# OfflineAI

A fully offline local AI assistant written in Python. No internet, no API keys, and no cloud services required.

## Features
- Offline chat
- Remembers conversation history locally
- Reads and stores custom knowledge
- Lightweight and easy to extend
- Publish-ready starter project

## Run
```bash
python main.py
```

## Commands
- /help
- /memory
- /clear
- /save
- /exit

## Notes
This project is intentionally simple and fully local. It is designed as a GitHub-ready starting point for your own offline AI assistant.
